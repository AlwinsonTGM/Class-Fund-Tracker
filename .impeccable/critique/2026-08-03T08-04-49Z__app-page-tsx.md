#### Overall Impression
The BSIS 201 Class Fund Tracker has strong functional bones and genuine domain utility, but its financial transparency goal is undermined by competing visual trends (`liquid-glass`, 3D card tilt, bounce easings, side-tab `border-l-4` cards, auto-popping modals). Toning down the noise will dramatically improve legibility and trust.

#### What's Working
1. **Domain-Grounded Privacy & Structure**: Seat-number ordering, privacy-masked student names (`First L.`), and Philippine Peso formatting build authentic classroom trust.
2. **Milestone Celebrations**: Integrated `ConfettiCanvas` and automated section Thank You modal when 100% weekly contribution is achieved.
3. **Responsive Core Layout**: Fluid transition between desktop top-tab pill navigation and mobile-friendly bottom bar navigation.

#### Priority Issues

##### [P1] Automated Patch Notes Modal Popup on Mount
- **Why it matters**: Auto-opening `PatchNotesModal` on page mount disrupts user intent, forces an unexpected modal context switch, and hides primary fund statistics.
- **Fix**: Replace auto-open logic with an unread dot badge on `PatchNotesButton` in the header, opening the modal only on user click.
- **Suggested command**: `$impeccable onboard app/page.tsx`

##### [P2] Artificial Side-Tab Accent Borders & Bounce Easings
- **Why it matters**: 8 occurrences of `border-l-4` side-accent borders (in `tasks-section` and `study-hub`) and 5 bounce/spring easings look dated and decrease card content space.
- **Fix**: Replace `border-l-4` with subtle inset borders/background tints, and switch bounce easings to smooth exponential easing (`ease-out-quart`).
- **Suggested command**: `$impeccable quieter app/page.tsx`

##### [P2] Navigation State Disconnect & Missing Keyboard Navigation
- **Why it matters**: `activeTab` relies solely on local `useState` without syncing to URL search params (`?tab=...`). Refreshing or sharing links resets the view to "Home", and power users cannot use keyboard shortcuts (`1-5`, `Arrow` keys, `/` search).
- **Fix**: Sync `activeTab` to URL search params via `useSearchParams` and add window `keydown` shortcut handlers.
- **Suggested command**: `$impeccable adapt app/page.tsx`

##### [P3] Unused Google Font Imports in Layout
- **Why it matters**: `app/layout.tsx` imports external Google Fonts (`Special Elite`, `Space Grotesk`) via `<link>` tags, but CSS `@theme` relies on `Geist`, adding unnecessary network overhead.
- **Fix**: Clean up unused Google Font links in `layout.tsx` or apply them purposefully to specific elements.
- **Suggested command**: `$impeccable typeset app/layout.tsx`
